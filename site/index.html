OTÁZKY A ODPOVEDE

Často kladené otázky

Potrebujem internet na čítanie lokálnej gateway?

Lokálne API používa sieťové spojenie medzi Windows počítačom a gateway. Internetové pripojenie samo osebe nie je podmienkou pre komunikáciu v LAN.

Je cloudová integrácia už pripravená?

Nie ako dokončené vydanie. Vyvíja sa samostatná vetva pre Ecowitt Web API v3.

Prečo tu nie je tlačidlo Stiahnuť?

Projekt je v alpha fáze a inštalačný balík .rmskin je podľa aktuálnej dokumentácie v príprave. Nechceme odkazovať na neoverené vydanie.

Budú fungovať všetky Ecowitt senzory?

Projekt obsahuje generický register senzorov a podporu kanálov CH1–CH8. Konkrétne dostupné údaje závisia od gateway, senzorov a stavu vývoja.
