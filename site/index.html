RAINMETER EDITION

Ako nainštalovať Cloud API beta

Pre vydanie v1.11.0-beta.6 je dostupný skutočný inštalátor. Ide o testovaciu beta verziu, nie o stabilnú aplikáciu.

1

Nainštalujte Rainmeter

Na Windows najprv nainštalujte aplikáciu Rainmeter.

2

Stiahnite beta .rmskin

Na stránke GitHub Release beta.6 stiahnite súbor EcowittWeather-v1.11.0-beta.6.rmskin, otvorte ho v Rainmeteri a potvrďte inštaláciu.

3

Nastavte Cloud API

V paneli Nastavenia zadajte Ecowitt Application Key, API Key a MAC adresu svojej stanice. Prihlasovacie heslo účtu sa do skinu nezadáva.

Bezpečnosť: Rainmeter beta umožňuje export konfigurácie do súboru .ecowittconfig. Tento súbor obsahuje API kľúče a nie je šifrovaný – nezverejňujte ho. Local API základ z vetvy main má odlišný postup nastavenia.

ODLIŠNÁ EDÍCIA

Rainmeter alebo Desktop?

Rainmeter Edition je skin pre Rainmeter s Cloud API beta balíkom .rmskin. Desktop Edition je samostatná aplikácia bez Rainmetera.

Desktop chráni uložené API kľúče pomocou Windows DPAPI. História v SQLite, grafy, export/import Desktop nastavení a samostatný inštalátor ešte nie sú súčasťou alpha.3.

OTÁZKY A ODPOVEDE

Často kladené otázky

Potrebujem internet na čítanie lokálnej gateway?

Local API používa sieťové spojenie medzi Windows počítačom a gateway; internet pri komunikácii v LAN nie je potrebný. Cloud API internetové pripojenie potrebuje.

Je Cloud API už dostupné na stiahnutie?

Áno. Rainmeter Cloud API v1.11.0-beta.6 je verejne dostupná beta s inštalátorom .rmskin. Nie je označená ako stabilné vydanie.

Aký je rozdiel medzi Local API a Cloud beta?

Local API základ vo vetve main komunikuje priamo s gateway. Verejná Rainmeter beta.6 používa Ecowitt Web API v3. Automatický režim Local/Web patrí do samostatnej Desktop Edition.

Kam mám vložiť Ecowitt API kľúče?

Application Key a API Key získate vo svojom profile na oficiálnej stránke ecowitt.net. Pre Cloud API ich zadávajte len do lokálnych nastavení aplikácie. Na tomto projektovom webe sa žiadne kľúče nevypĺňajú.

Je export konfigurácie bezpečný na zdieľanie?

Nie. Súbor .ecowittconfig z Rainmeter beta obsahuje citlivé API kľúče a nie je šifrovaný. Neprikladajte ho do verejných issue ani e-mailov neznámym príjemcom.

Budú fungovať všetky Ecowitt senzory?

Projekt používa generický register senzorov a podporu CH1–CH8. Skutočne dostupné údaje závisia od gateway, senzorov a konkrétnej edície.
