STEP 1 · INSTALLATION

Download and first installation

You need Windows, Rainmeter, internet access and an Ecowitt weather station accessible through your Ecowitt account.

1

Install Rainmeter

Download Rainmeter from the official rainmeter.net site ↗ and install it on Windows.

2

Download public beta.6

Open the beta.6 GitHub Release ↗. Under Assets download EcowittWeather-v1.11.0-beta.6.rmskin. A ZIP package is available as a manual-install alternative.

3

Open the .rmskin file

Open the downloaded file with Rainmeter and confirm Install. The package installs EcowittWeather and opens the Settings panel afterwards.

This is a public beta prerelease, not a stable version. SHA-256 checksum files are also available. Download only from the official GitHub repository.

STEP 2 · ECOWITT

Where to get API keys and station MAC

Rainmeter Cloud API needs an Application Key, an API Key and the station MAC address. Do not enter your Ecowitt login password into Rainmeter.

1

Open ecowitt.net

Sign in directly on the official ecowitt.net site ↗. The Ecowitt mobile app does not provide API key creation.

2

Find User Profile

Click the account icon at the top right and open User Profile. Create or copy your Application Key and API Key there. The api.doc reference is usually available in the same area.

3

Find your station MAC

Identify the MAC address of your own weather station from its device/account information. Rainmeter beta requires manual MAC entry; automatic station list selection is a Desktop Edition feature.

Official help: Ecowitt – How do I find my app & api keys? ↗. Ecowitt may change menu labels; use the current User Profile on its official website.

STEP 3 · FIRST RUN

Configure Cloud API and open METEO

After installation, the Rainmeter panel is labeled ECOWITT CLOUD API – NASTAVENIA (Settings). Beta.6 uses Slovak control labels. Credentials stay in the local skin, not on this website.

1

Enter the three fields

Click Application Key, API Key and MAC stanice (station MAC). Press Enter after each value. MAC example: AA:BB:CC:DD:EE:FF – enter the actual address of your station.

2

Test connectivity

Initially keep Refresh (s) at 60. Click TEST CLOUD API. A successful result looks like OK | code=0 | … | sekcie=N; errors start with CHYBA, CHYBA API or CHYBA HTTP.

3

Open the weather skin

After a successful test click OTVORIŤ METEO SKIN (open METEO). You can optionally label CH1–CH8 using NÁZVY SENZOROV (sensor names). Only available readings are displayed.

LOCAL SETTINGS

Where are values stored?

Keys and station MAC are stored locally in CloudSecrets.inc. This file is excluded from public release packages and source control. User labels and refresh preferences live in UserVariables.inc.

SEPARATE EDITIONS

Cloud beta is not hybrid Auto mode

The Rainmeter beta.6 installer uses Ecowitt Web API v3 and needs internet. The separate Local API source baseline reads /get_livedata_info. Local/Web Auto fallback is documented for Desktop Edition.

VERIFY

Diagnostics and connection troubleshooting

If readings do not appear, start with the built-in Settings test. Enable detailed debug logging only when needed.

BASIC CHECKS

TEST CLOUD API

  • Chýba: … indicates a missing Application Key, API Key or MAC. Complete the field and press Enter.
  • CHYBA API: verify credentials, station MAC and Ecowitt account permissions.
  • CHYBA HTTP: check internet, firewall/proxy and service availability.
  • If the test passes but METEO is empty, refresh the skin and verify your station is returning live readings.
DEBUG / LOG

DIAGNOSTIKA

  • Click DIAGNOSTIKA (diagnostics) in Settings, then DEBUG ON if needed.
  • Open METEO, wait for a new API sample, and use OBNOVIŤ (refresh) or OTVORIŤ LOG (open log) in Diagnostics.
  • When done, choose DEBUG OFF. The log is @Resources/Diagnostics/ecowitt_cloud_debug.txt.

The source is designed not to write API keys to the debug file. However, always review logs and errors before sharing; never publish a full URL containing credentials.

MAINTENANCE

Update checks and backups

Cloud beta has an in-skin updater with Stable, Beta and Development channels.

1

Open the Updates panel

In Settings click AKTUALIZÁCIE (updates), or the METEO CLOUD heading. You will see installed and available versions plus ČO JE NOVÉ (what's new).

2

Use the Beta channel

For public beta releases select BETA and click SKONTROLOVAŤ (check). STABLE targets non-prerelease versions and DEVELOPMENT follows development snapshots.

3

Update after checking

Verify the offered Rainmeter release tag and notes on GitHub; then use AKTUALIZOVAŤ (update). The updater creates a backup, checks SHA-256 when available, preserves local user files and refreshes Rainmeter.

Updater backups: %LOCALAPPDATA%\EcowittRainmeter\Backups. The public updater is not intended to overwrite Git-managed development checkouts.

SECURITY

Export and import configuration

Rainmeter beta.6 supports transferring settings through .ecowittconfig files.

SENSITIVE FILE

EXPORT

In Settings click EXPORT, choose a file location and save. The bundle contains Application Key, API Key, station MAC, sensor labels, refresh interval and update channel.

Warning: the export is not encrypted. Never publish or send it to untrusted recipients.

TRUSTED PACKAGE ONLY

IMPORT

In Settings click IMPORT and select your own trusted configuration package. The app checks its manifest, backs up the previous settings, and refreshes Rainmeter after a successful import.

Backup location: %LOCALAPPDATA%\EcowittRainmeter\ConfigBackups.

Do not attach the export to GitHub issues, public chat messages or untrusted emails. If keys leak, regenerate them in Ecowitt and replace them in local Settings.

FAQ

Frequently asked questions

Quick help for Rainmeter Cloud API beta.6 users.

Should I enter my API keys on this website?

No. This is a static guide. Sign in directly at ecowitt.net and enter your API credentials only in the installed Rainmeter skin's local Settings.

Why do I not see all CH1–CH8 sensors?

Readings depend on which sensors exist and which fields your Ecowitt Cloud API response includes. The skin supports dynamic channels, but not every possible sensor type is guaranteed.

Can I use Local API without internet?

Yes, there is a separate Local API development baseline. However, this specific Rainmeter beta.6 installer is for Cloud API. Local/Web/Auto is available in the separate Desktop Edition.

What if an update fails?

Check the selected channel in AKTUALIZÁCIE, the SKONTROLOVAŤ result and the release tag on GitHub. Preserve the previous configuration and backup before retrying.

Can I share my configuration export or complete diagnostic log?

Not without inspection. A .ecowittconfig export contains unencrypted API keys. Review and redact diagnostics before sending any log.
