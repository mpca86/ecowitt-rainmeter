DEVELOPMENT BASELINE · v1.10.0-alpha

Ecowitt Local API

The main branch baseline reads your gateway directly through /get_livedata_info. The PC and gateway must be reachable over LAN or an appropriate VPN.

  • No Ecowitt API credentials required for local measurements
  • Sensor readings, trends, CSV history and diagnostics
  • Not the same package as the Cloud API beta installer linked below

PUBLIC BETA · v1.11.0-beta.6

Ecowitt Cloud API v3

The released Rainmeter beta uses Ecowitt Web API v3. Configuration requires an Application Key, API Key and station MAC address; these are entered in the Rainmeter skin, never on this website.

  • Official beta .rmskin and ZIP on GitHub
  • In-skin updates, diagnostics and configuration export/import
  • No automatic Local/Cloud failover is claimed for this Rainmeter beta

RAINMETER EDITION

Install the Cloud API beta

A real installer is available for v1.11.0-beta.6. This is a testing beta, not a stable application release.

1

Install Rainmeter

First install Rainmeter on Windows.

2

Download beta .rmskin

Open the beta.6 GitHub Release, download EcowittWeather-v1.11.0-beta.6.rmskin, open it with Rainmeter and confirm installation.

3

Configure Cloud API

Enter your Ecowitt Application Key, API Key and station MAC address in the Settings panel. Do not enter your Ecowitt account password into the skin.

Security: Rainmeter beta can export configuration to an .ecowittconfig file. It contains API keys and is not encrypted – never post or share it publicly. The Local API baseline on main uses a different setup process.

SEPARATE EDITION

Rainmeter or Desktop?

Rainmeter Edition is a Rainmeter skin with a Cloud API beta .rmskin package. Desktop Edition is a standalone application that does not need Rainmeter.

Desktop protects stored API keys with Windows DPAPI. SQLite history, charts, Desktop configuration export/import and a standalone installer are not included in alpha.3.

QUESTIONS

Frequently asked questions

Do I need internet access to read a local gateway?

Local API uses the network connection between your Windows PC and gateway; internet access is not required for LAN communication. Cloud API does require internet access.

Can I download Cloud API now?

Yes. Rainmeter Cloud API v1.11.0-beta.6 is a public beta with a .rmskin installer. It is not a stable release.

What is the difference between Local API and Cloud beta?

The Local API baseline on main connects directly to your gateway. The released Rainmeter beta.6 uses Ecowitt Web API v3. Automatic Local/Web mode is a Desktop Edition feature.

Where should I enter my Ecowitt API keys?

Get your Application Key and API Key from your profile on the official ecowitt.net website. Enter them only in the application's local settings. This project website never asks for credentials.

Is a configuration export safe to share?

No. A Rainmeter beta .ecowittconfig file contains sensitive API keys and is not encrypted. Do not attach it to public issues or send it to untrusted recipients.

Will all Ecowitt sensors work?

The project uses a generic sensor registry and CH1–CH8 support. Actual readings depend on your gateway, sensors and edition.
