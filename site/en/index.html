QUESTIONS

Frequently asked questions

Do I need the internet to read a local gateway?

Local API relies on network connectivity between your Windows PC and gateway. Internet access itself is not required for LAN communication.

Is cloud integration ready?

Not as a completed release. An Ecowitt Web API v3 adapter is under development in a separate branch.

Why isn't there a Download button?

The project is at the alpha stage, and according to the current documentation the .rmskin package is still being prepared. We don't link to an unverified release.

Will every Ecowitt sensor work?

The project includes a generic sensor registry and CH1–CH8 channel support. Actual measurements depend on your gateway, connected sensors and development status.
