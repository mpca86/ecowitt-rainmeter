KROK 1

Nainštalujte zdrojový Local skin

Najprv nainštalujte Rainmeter. Local API vo vetve main sa momentálne distribuuje ako zdrojový kód, nie ako potvrdený samostatný .rmskin balík.

1

Pripravte Rainmeter

Nainštalujte Rainmeter z oficiálneho webu ↗ na Windows a spustite jeho správu skinov.

2

Stiahnite vetvu main

Otvorte GitHub ZIP vetvy main ↗ a rozbaľte archív. V ňom nájdite src/EcowittWeather/ s priečinkami Meteo, Settings, Diagnostics a @Resources.

3

Skopírujte celý priečinok

Celý priečinok EcowittWeather preneste do priečinka Rainmeter Skins (často Dokumenty\Rainmeter\Skins; presnú cestu zistite v nastavení Rainmetera). Zachovajte štruktúru vrátane @Resources.

Nie Cloud inštalátor: verejný v1.11.0-beta.6.rmskin používa Web API v3. Na Local postup nepreberajte Cloud balík ani Cloud nastavenia; tento návod používa zdrojové súbory main.

KROK 2

Nájdite gateway a otestujte JSON

Vyžaduje sa podporovaný Ecowitt gateway s lokálnym HTTP endpointom. Samotný bezdrôtový senzor bez gatewaya nestačí.

PRÍPRAVA

IP adresa a prístup

Zistite IP adresu gatewaya napríklad v DHCP zozname routera. Počítač a gateway musia byť navzájom dostupné v LAN alebo cez vhodnú VPN. Skontrolujte klientsku izoláciu Wi-Fi, VLAN smerovanie a firewall.

  • Príklad IP: 192.168.1.50 – len ilustračná
  • Štandardný port podľa Variables.inc: 80
  • IP a port patria gatewayu, nie účtu ecowitt.net
ODPOVEĎ API

Kontrola z prehliadača

V prehliadači na tom istom PC otvorte:

http://192.168.1.50:80/get_livedata_info

Nahraďte IP a port skutočnými údajmi. Očakávajte JSON odpoveď kompatibilného zariadenia. Súčasný test v Rainmeteri hľadá v odpovedi položky common_list a debug.

Bezpečnosť: ide o nezabezpečené http:// na súkromnej sieti. Endpoint nevystavujte port forwardingom na internet; pri vzdialenom používaní uprednostnite bezpečnú VPN.

KROK 3

Nastavte Rainmeter a otestujte pripojenie

Pri konfigurácii Local skinu nezadávate Application Key, API Key ani MAC stanice. Zadáva sa IP alebo hostname a port.

1

Otvorte Nastavenia

V Rainmeteri obnovte zoznam skinov a načítajte EcowittWeather\Settings\Settings.ini. Panel nesie názov ECOWITT WEATHER – NASTAVENIA.

2

Vyplňte Gateway address a Port

Do Gateway address zadajte len IP/hostname bez http:// a bez portu. Do samostatného poľa Port zadajte 80 alebo port vášho gatewaya. Po každom zadaní potvrďte Enter.

3

Spustite test

Kliknite TEST PRIPOJENIA. Pri očakávanej odpovedi sa zobrazí Pripojené – Local API odpovedá. Pri zlyhaní sa objaví hlásenie o adrese, porte a routingu/firewalle. Potom kliknite OTVORIŤ METEO SKIN.

Poznámka k verzii: panel zapisuje hodnoty do @Resources/Includes/Variables.inc. Pred prepísaním zdrojového priečinka si urobte zálohu vlastného nastavenia.

KROK 4

Zobrazovanie meraní a história

Local skin používa Rainmeter WebParser, JSON dekodér a generický Ecowitt parser. Zobrazí iba polia, ktoré dostupná odpoveď gatewaya poskytuje.

METEO

Dostupné údaje

Outdoor/indoor teplota a vlhkosť, vietor, UV, slnečné žiarenie, zrážky a tlak. Podporované senzory CH1–CH8 sa spracúvajú dynamicky a neexistujúce kanály sa skrývajú.

Aliasy kanálov Channel1Label až Channel8Label a GatewayLabel možno upravovať v Variables.inc.

HISTÓRIA

Lokálne CSV a trendy

Pri behu METEO skinu sa vzorky ukladajú do Meteo/meteo_history.csv. Implementované sú napríklad 15-minútové teplotné trendy a 3-hodinová tendencia tlaku.

Po prvom spustení nemusí byť dostatok historických vzoriek na výpočet trendov. Ide o lokálny CSV súbor, nie Cloud export.

KROK 5

Diagnostika a riešenie chýb

Ak browser nevie načítať endpoint, najprv riešte sieť alebo kompatibilitu gatewaya. Ak JSON funguje a METEO nie, pokračujte kontrolou Rainmetera.

KONTROLA SPOJENIA

Najčastejšie problémy

  • Žiadna odpoveď: správna IP, port, zapnutý gateway a dostupnosť PC → gateway.
  • HTTP chyba/timeout: VLAN, Wi-Fi izolácia, firewall, VPN trasa alebo nepodporovaný endpoint.
  • JSON je dostupný, test zlyháva: overte, či odpoveď obsahuje očakávané položky common_list a debug.
  • Prázdny METEO skin: skontrolujte, či je načítaný Meteo.ini, či parser dostáva platné merania a či sú pripojené senzory.
PARSER DEBUG

Diagnostický súbor

V súbore @Resources/Includes/Variables.inc dočasne zmeňte DebugParser=0 na DebugParser=1, obnovte METEO a počkajte na platnú vzorku.

Potom cez správu Rainmetera otvorte Diagnostics/Diagnostics.ini alebo prezrite @Resources/Diagnostics/ecowitt_debug.txt. Po diagnostike vráťte DebugParser=0.

Vo verzii main nie je v paneli Nastavenia tlačidlo DIAGNOSTIKA z Cloud beta. Diagnostický panel sa načítava samostatne. Pred poskytnutím logu skontrolujte údaje o sieti, miestnych názvoch a stanici.

OTÁZKY

Najčastejšie otázky

Najprv skúste lokálny endpoint a TEST PRIPOJENIA, až následne upravujte parser.

Potrebujem ecowitt.net účet alebo API kľúče?

Na tomto lokálnom Rainmeter zdrojovom základe nie. Používa priame HTTP volanie na gateway v LAN/VPN; kľúče a MAC pre Cloud API sem nepatria.

Kde stiahnem .rmskin pre Local API?

V aktuálnych podkladoch vetvy main nie je potvrdený samostatný verejný Local API .rmskin release. Použite manuálnu inštaláciu zdrojového priečinka EcowittWeather podľa tohto návodu.

Prečo TEST PRIPOJENIA hlási Bez odpovede, hoci vidím JSON?

Test v main kontroluje textový tvar odpovede s položkami common_list a debug. Ak gateway vracia inú JSON schému, test nemusí prejsť a parser tiež nemusí údaje správne interpretovať.

Je potrebný internet?

Pre lokálne merania medzi Rainmeter PC a gatewayom internet nie je potrebný, ak je sieťové spojenie a lokálne HTTP rozhranie funkčné. Na stiahnutie Rainmetera a zdrojového kódu internet potrebujete.

Kde sa ukladajú nastavenia a história?

Nastavenia v @Resources/Includes/Variables.inc; lokálna história v Meteo/meteo_history.csv. Pred ručnou aktualizáciou zdroja si ich zálohujte.

Čo keď gateway a PC sú v rôznych VLAN?

Potrebujete routing medzi podsieťami, pravidlá firewallu povoľujúce potrebný port a neblokujúce klientsku izoláciu. Neotvárajte endpoint port forwardingom na internet.
