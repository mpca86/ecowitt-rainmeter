KROK 1 · INŠTALÁCIA

Stiahnutie a prvá inštalácia

Potrebujete Windows, aplikáciu Rainmeter, internetové pripojenie a meteostanicu Ecowitt dostupnú cez váš Ecowitt účet.

1

Pripravte Rainmeter

Zo stránky rainmeter.net ↗ nainštalujte Rainmeter do Windows.

2

Stiahnite verejnú beta.6

Otvorte GitHub Release beta.6 ↗. V Assets vyberte EcowittWeather-v1.11.0-beta.6.rmskin. ZIP balík je alternatíva pre manuálnu inštaláciu.

3

Otvorte .rmskin

Dvojklikom otvorte stiahnutý súbor v Rainmeteri a potvrďte Install. Balík nainštaluje skin EcowittWeather a po inštalácii otvorí panel Nastavenia.

Ide o verejnú beta verziu, nie stabilné vydanie. K balíku sú dostupné aj kontrolné súčty SHA-256. Stiahnutie vykonávajte z oficiálneho GitHub repozitára.

KROK 2 · ECOWITT

Kde získam API kľúče a MAC?

Rainmeter Cloud API potrebuje Application Key, API Key a MAC adresu meteostanice. Prihlasovacie heslo do účtu sa do Rainmetera nezadáva.

1

Otvorte ecowitt.net

Vo vlastnom prehliadači otvorte ecowitt.net ↗ a prihláste sa na oficiálnej stránke. V mobilnej aplikácii Ecowitt sa tieto kľúče nevytvárajú.

2

Prejdite na User Profile

Kliknite na ikonu účtu v pravom hornom rohu a otvorte User Profile. V profile si vytvorte alebo skopírujte oba kľúče Application Key a API Key; býva tam aj dokument api.doc.

3

Pripravte MAC stanice

Z údajov svojej meteostanice si zistite jej MAC adresu. Rainmeter beta vyžaduje ručné zadanie MAC; funkcia načítania zoznamu staníc patrí do samostatnej Desktop Edition.

Oficiálna pomoc: Ecowitt – How do I find my app & api keys? ↗. Ak sa web Ecowitt zmení, použite aktuálnu podobu časti User Profile.

KROK 3 · PRVÉ SPUSTENIE

Nastavte Cloud API a zobrazte METEO

Po inštalácii sa otvorí panel ECOWITT CLOUD API – NASTAVENIA. Všetky hodnoty sa zadávajú do lokálneho skinu, nie na tento web.

1

Vyplňte tri údaje

Kliknite na Application Key, API Key a MAC stanice. Každý údaj po zadaní potvrďte klávesom Enter. Príklad formátu MAC: AA:BB:CC:DD:EE:FF – použite svoju skutočnú adresu.

2

Otestujte pripojenie

Na úvod ponechajte Refresh (s) na 60. Stlačte TEST CLOUD API. Úspešný výsledok vyzerá ako OK | code=0 | … | sekcie=N; chyby začínajú slovami CHYBA, CHYBA API alebo CHYBA HTTP.

3

Otvorte Meteo skin

Po úspešnom teste stlačte OTVORIŤ METEO SKIN. Voliteľne nastavte pomenovania kanálov CH1–CH8 cez NÁZVY SENZOROV. Zobrazujú sa iba údaje, ktoré vaše zariadenie poskytuje.

LOKÁLNE NASTAVENIA

Kde sú údaje uložené?

API kľúče aj MAC sa ukladajú lokálne do CloudSecrets.inc. Zostávajú mimo distribučných balíkov a zdrojového repozitára. Používateľské názvy a interval sú v UserVariables.inc.

ROZDIELNE EDÍCIE

Cloud beta nie je hybridný režim

Rainmeter beta.6 používa Ecowitt Web API v3 a potrebuje internet. Local API z vetvy main používa /get_livedata_info. Automatický režim Local/Web patrí Desktop Edition.

OVERENIE

Diagnostika a riešenie spojenia

Keď sa merania nezobrazujú, začnite testom v Nastaveniach. Diagnostiku zapnite iba keď potrebujete detailnejšie údaje.

ZÁKLADNÁ KONTROLA

TEST CLOUD API

  • Chýba: … znamená nevyplnený Application Key, API Key alebo MAC. Vyplňte pole a potvrďte Enter.
  • CHYBA API: skontrolujte správnosť kľúčov, MAC a oprávnenia stanice v účte Ecowitt.
  • CHYBA HTTP: skontrolujte pripojenie k internetu, firewall/proxy a dostupnosť API.
  • Keď test prejde, ale METEO je prázdne, obnovte skin a overte, či stanica skutočne poskytuje merania.
DEBUG / LOG

DIAGNOSTIKA

  • V Nastaveniach kliknite na DIAGNOSTIKA a podľa potreby na DEBUG ON.
  • Otvorte METEO, počkajte na ďalšiu API vzorku a v diagnostike kliknite OBNOVIŤ alebo OTVORIŤ LOG.
  • Po skončení kliknite DEBUG OFF. Záznam nájdete v @Resources/Diagnostics/ecowitt_cloud_debug.txt.

Zdrojový kód je navrhnutý tak, aby nezapisoval API kľúče do debug súboru. Napriek tomu pred zdieľaním vždy skontrolujte log a chybové hlásenia; neposielajte celé URL s prístupovými údajmi.

ÚDRŽBA

Kontrola aktualizácií a zálohy

Beta má vlastný panel aktualizácií s kanálmi Stable, Beta a Development.

1

Otvorte Aktualizácie

V Nastaveniach kliknite na AKTUALIZÁCIE, prípadne na nadpis METEO CLOUD. Zobrazí sa miestna verzia, dostupná verzia aj sekcia ČO JE NOVÉ.

2

Vyberte Beta kanál

Pre verejné beta vydania zvoľte BETA a kliknite SKONTROLOVAŤ. Kanál STABLE patrí finálnym vydaniam, DEVELOPMENT vývojovým snímkam.

3

Aktualizujte po kontrole

Overte tag a obsah ponúknutého Rainmeter vydania na GitHube, potom kliknite AKTUALIZOVAŤ. Updater vytvorí zálohu, podľa dostupnosti overí SHA-256, zachová používateľské súbory a obnoví Rainmeter.

Zálohy aktualizácií: %LOCALAPPDATA%\EcowittRainmeter\Backups. Vývojové inštalácie spravované cez Git nie sú určené na prepisovanie verejným aktualizátorom.

BEZPEČNOSŤ

Export a import konfigurácie

Rainmeter beta.6 podporuje prenos konfigurácie vo formáte .ecowittconfig.

CITLIVÝ SÚBOR

EXPORT

V Nastaveniach kliknite EXPORT, vyberte umiestnenie a uložte súbor. Obsahuje Application Key, API Key, MAC, názvy senzorov, interval a aktualizačný kanál.

Varovanie: súbor nie je šifrovaný. Nezverejňujte ho ani neposielajte nedôveryhodným príjemcom.

VLASTNÝ BALÍK

IMPORT

V Nastaveniach kliknite IMPORT a zvoľte vlastný dôveryhodný balík. Aplikácia kontroluje manifest a pred prepísaním vykoná zálohu, potom obnoví Rainmeter.

Zálohy sú v %LOCALAPPDATA%\EcowittRainmeter\ConfigBackups.

Nepoužívajte export ako verejnú prílohu v GitHub Issues, konverzácii ani e-maile. Pri úniku kľúčov ich obnovte v Ecowitt a nahraďte v miestnych nastaveniach.

FAQ

Najčastejšie otázky

Rýchla pomoc pre používateľov Rainmeter Cloud API beta.6.

Musím na tento web zadávať API kľúče?

Nie. Tento web je iba statický návod. Prihláste sa priamo na ecowitt.net, kľúče zadávajte výlučne do lokálnych nastavení Rainmeter skinu.

Prečo nevidím senzory CH1–CH8?

Dostupnosť závisí od senzorov a údajov, ktoré Ecowitt Cloud API skutočne vracia. Skin podporuje dynamické kanály, ale nemusí zobrazovať všetky možné typy senzorov.

Môžem používať Local API bez internetu?

Áno, existuje samostatný Local API vývojový základ. Tento konkrétny Rainmeter beta.6 balík je však pre Cloud API; hybridný Auto režim je zdokumentovaný pre Desktop Edition.

Čo ak sa nepodarí aktualizácia?

Skontrolujte zvolený kanál v AKTUALIZÁCIE, výsledok SKONTROLOVAŤ a tag vydania na GitHube. Pred ďalším pokusom zachovajte pôvodnú konfiguráciu a zálohu.

Je bezpečné zdieľať export alebo celý diagnostický log?

Nie bez kontroly. Export .ecowittconfig obsahuje nešifrované API kľúče. Diagnostický log pred zdieľaním prezrite a odstráňte prípadné citlivé údaje.
