# Ecowitt Weather – Desktop Edition

Samostatná Windows aplikácia pre Ecowitt stanice a senzory.

Plánovaný stack:

- .NET 8
- WPF
- MVVM
- Local API + Ecowitt Web API v3
- SQLite história
- Windows DPAPI pre citlivé údaje
- viac profilov / staníc
- viac nezávislých widgetov

Architektúra: [docs/DESKTOP_ARCHITECTURE.md](../../docs/DESKTOP_ARCHITECTURE.md)

## Stav

Počiatočný návrh architektúry. Rainmeter Edition zostáva funkčná a distribuuje sa nezávisle.
